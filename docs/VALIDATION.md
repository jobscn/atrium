## 0.1.0 已归档结果

原生应用发现（电视入口优先）、收藏排序、分钟时钟、系统设置、默认 Home 角色请求、临时小米桌面访问、媒体会话能力控制、全局 VPN 检测与 Sockstun 打开降级。

## 已实际检查
最终发行 APK 在官方 AOSP Android 14 / API 34 模拟器安装成功、冷启动成功。1920×1080 原生截图确认应用图标、播放器空态和 VPN 未检测到状态；方向键及确认打开设置，返回键退出设置并恢复入口焦点。检查的最近运行日志未发现 Atrium 的 FATAL EXCEPTION；这不是长期稳定性结论。

## 已知问题及边界
- 当前 AOSP 截图首个应用名称未显示；已有空名称回退，但该视觉问题原因未确认。
- 官方 Android TV 模拟器曾显示首页，随后系统出现 ANR / 黑屏；AOSP 软件仿真启动期间也出现系统进程及 System UI ANR。清除可见系统等待提示后只完成上述最小烟测。不能据此推断真实电视帧率或长期稳定性。
- 原生媒体回调、真实音乐应用兼容、权限撤销及多会话尚未完成运行验收。HTML 示例不是原生验证证据。
- VPN 仅显示系统可见状态，不能保证识别具体提供者；当前不支持直接开关 Sockstun，按钮打开其应用操作。
- 无实体电视验收，不宣称已完成默认桌面替换或小爱兼容验证。
